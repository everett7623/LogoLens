# LogoLens 使用指南

本文介绍 LogoLens `0.1.0` 的安装、日常使用、下载规则和常见问题。

## 运行要求

- 支持 Manifest V3 的桌面版 Chrome。
- 需要扫描的页面必须使用 `http://` 或 `https://` 协议。
- 通过 GitHub 安装时，需要开启 Chrome“开发者模式”。

LogoLens 不需要账号、登录、后端服务或单独配置。

## 安装

### 安装 Release 版本

1. 进入项目的 [Releases](https://github.com/everett7623/LogoLens/releases/latest) 页面。
2. 下载 `LogoLens-v0.1.0.zip`。
3. 将 ZIP 解压到一个长期保留的目录。安装后不要移动或删除该目录。
4. 在 Chrome 地址栏输入 `chrome://extensions/`。
5. 开启右上角的“开发者模式”。
6. 点击“加载已解压的扩展程序”。
7. 选择包含 `manifest.json` 的解压目录。

安装完成后，可在扩展菜单中将 LogoLens 固定到工具栏。

### 安装源码版本

```bash
git clone https://github.com/everett7623/LogoLens.git
```

在 `chrome://extensions/` 中选择“加载已解压的扩展程序”，然后选择仓库根目录。

更新源码后，需要在扩展管理页点击 LogoLens 卡片上的“重新加载”。

## 扫描网页资源

1. 打开需要检查的网站并等待主要内容加载完成。
2. 点击 Chrome 工具栏中的 LogoLens 图标。
3. 弹窗会显示当前页面标题、域名和资源总数。
4. 扫描完成后，结果默认按 Logo 优先、尺寸由大到小排列。

扫描覆盖的全部资源来源见 [README 的识别范围](../README.md#识别范围)。同一资源地址只会保留一次，单次扫描最多展示 60 项。

其中内嵌 SVG 有两种情况：引用同页 sprite（`<use href="#icon">`）的 SVG 会把被引用图形一并打包，因此可以正常预览和下载；引用外部 sprite 文件（`sprite.svg#icon`）的 SVG 离开页面后无法还原，会被跳过。

## 筛选结果

顶部提供三个页签：

- **全部**：显示本次扫描发现的所有资源。
- **Logo**：只显示 Logo、结构化图片、社交图片和内嵌 SVG。
- **Favicon**：只显示网站图标和 Web App Manifest 图标。

页签右侧的数字表示对应类别的资源数量。底部批量操作只作用于当前筛选结果。

## 预览与复制

- 点击非内嵌图片的缩略图，可在新标签页打开原始资源。
- 内嵌 SVG 使用 `data:` 地址，只在卡片内预览，不会打开新标签页。
- 点击单个卡片的“复制”，可复制该资源地址。
- 点击“复制当前列表”，可按当前排序复制当前筛选结果，每行一个地址。

如果页面或浏览器禁止剪贴板操作，弹窗会显示复制失败提示。

## 下载资源

### 单项下载

点击资源卡片上的“下载”，Chrome 会显示保存位置选择框。默认路径格式为：

```text
LogoLens/{域名}/{类别}-{序号}.{扩展名}
```

### 批量下载

点击“下载当前列表”后，LogoLens 会依次创建下载任务，默认目录结构为：

```text
LogoLens/{域名}/{类别}-{序号}.{扩展名}
```

Chrome 可能根据下载设置询问是否允许多个文件下载。远程资源需要登录、含有防盗链规则或已经失效时，个别项目可能下载失败。

## 重新扫描

当网页发生以下变化时，点击当前页面卡片右侧的重新扫描按钮：

- 单页应用完成了页面切换。
- Logo 或图片在滚动、交互后才加载。
- 网站主题或品牌资源刚刚切换。
- 首次扫描时页面仍处于加载状态。

重新扫描会替换弹窗中的内存结果，不会在浏览器中保存历史记录。

## 无法使用的页面

Chrome 会阻止扩展扫描以下页面：

- `chrome://`、`edge://` 等浏览器内部页面。
- Chrome Web Store 等受保护页面。
- 本地浏览器设置、扩展管理和新标签页。

请切换到普通的 `http://` 或 `https://` 页面后重试。

## 常见问题

### 没有找到目标 Logo

等待页面加载完成后重新扫描。CSS 背景图和开放 shadow root 内的资源自 `0.1.0` 起已支持；但网站通过 Canvas 绘制、封闭（`closed`）shadow root，或完全非语义化的结构展示 Logo 时，当前版本仍可能无法识别。

### 缩略图无法显示

原始服务器可能限制跨站加载、要求登录或已经删除资源。可尝试点击缩略图打开原始地址。

### 下载失败

检查 Chrome 下载权限、默认下载目录和多文件下载设置，并确认资源地址仍可访问。

### 修改源码后界面没有更新

进入 `chrome://extensions/`，在 LogoLens 卡片上点击“重新加载”，然后关闭并重新打开弹窗。仅刷新当前网页不会重新加载扩展代码。

## 隐私说明

LogoLens 只在用户主动点击扩展时访问当前标签页。扫描、分类和结果状态都在本地完成，扩展关闭后不会保留结果。

为了显示或下载页面声明的图片，以及读取 Web App Manifest，浏览器会连接对应资源服务器。请求可能包含常规网络信息，如 IP 地址、User-Agent 和资源 URL 中已有的参数。

完整说明请查看 [隐私政策](../PRIVACY.md)。

## 卸载

在 `chrome://extensions/` 的 LogoLens 卡片中点击“移除”即可。LogoLens 不创建账号或云端数据，也不保存扫描历史，因此无需额外清理。
